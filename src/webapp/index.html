How this system is built

  • Factory Method — DocumentProcessorFactory declares the factory method that each of the five concrete factories overrides to create the right DocumentProcessor for its document type.
  • Abstract Factory — CountryComplianceFactory creates a matching family of country-specific objects (a tax id validator and a document-rules object) so the two never get mismatched between countries.
  • Singleton — DocumentProcessorFactoryProvider and CountryComplianceRegistry are the single, shared access points to those factories for the whole application.
  • Template Method — AbstractDocumentProcessor fixes the common processing steps (empty-file guard, checksum, common metadata) and leaves the type-specific extraction to each subclass.

Countries currently supported: Colombia, Mexico, Brazil, Spain and the United States — each with its own accepted document types, maximum file size and fiscal id format, enforced entirely on the backend.
